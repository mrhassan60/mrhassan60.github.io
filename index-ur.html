پروفائل

میں اس وقت یونیورسٹی پیرس-دوفین میں انفارمیشن سسٹمز مینجمنٹ (GSI) میں ماسٹر کر رہا ہوں۔ مجھے سسٹمز انجینیئرنگ میں ۶ سال سے زیادہ کا تجربہ ہے، جن میں سے ۳ سال سے زیادہ یونیورسٹی پیرس-دوفین میں گزرے ہیں۔ میری مہارتوں میں ویب سرور ایڈمنسٹریشن (IIS، Apache، Nginx)، ڈویلپمنٹ (PHP، HTML، CSS، Python، MySQL) اور آٹومیشن (Ansible، PowerShell، Bash) شامل ہیں۔ مجھے ورچوئلائزیشن اور ہائی اویلیبلٹی (Hyper-V، Proxmox)، کنٹینرائزیشن (Docker) اور AI حل تعینات کرنے (LLM، RAG) میں بھی مہارت حاصل ہے۔ میں ونڈوز سرور ایڈمنسٹریشن (AD، DNS، GPO)، Linux Debian، مانیٹرنگ (Nagios Core، CheckMK) اور بیک اپ (Veeam Backup، Proxmox Backup) میں بھی ماہر ہوں۔ میں DevOps اپروچ کے ذریعے انفراسٹرکچر کو بہتر بناتا ہوں اور تکنیکی و انتظامی ذمہ داریوں والے عہدے کی طرف بڑھنا چاہتا ہوں۔

سسٹمز اور نیٹ ورک انجینیئر - Université Paris-Dauphine، پیرس

نومبر ۲۰۲۳ - تاحال

AI اور Docker:

  • LLMs (Mistral، GPT-OSS، OpenWebUI، Ollama) پر مبنی ایک پرائیویٹ AI سرور ڈیزائن، تعینات اور محفوظ کیا، Docker کے ساتھ کنٹینرائز کیا، RAG آرکیٹیکچر، SearxNG سرچ انجن اور Amazon Bedrock انٹیگریشن کے ساتھ، ۱۰,۰۰۰ صارفین تک سنبھالنے کی صلاحیت۔

سسٹمز اور سروسز:

  • Active Directory (AD) سرور ایڈمنسٹریشن: صارفین، گروپس اور GPO مینجمنٹ۔
  • DNS سرور ایڈمنسٹریشن (Windows Server): زون مینجمنٹ اور نام کی تفریق۔
  • Windows Server ویب سرورز کا قیام اور ایڈمنسٹریشن: IIS، ویب سائٹ ہوسٹنگ، HTTPS کنفیگریشن، ریورس پراکسی اور MySQL/MariaDB ڈیٹابیس مینجمنٹ۔
  • Linux (Debian) ویب سرورز کا قیام اور ایڈمنسٹریشن: Apache2، Nginx اور MySQL/MariaDB ڈیٹابیس ایڈمنسٹریشن۔
  • آئی ٹی ہارڈویئر مینجمنٹ: PCs اور سرورز کی انسٹالیشن، مینٹیننس اور اسمبلی۔
  • MDT اور WDS کے ذریعے PC تعیناتی: Windows 10/11، ایپلیکیشنز اور ڈرائیورز کی خودکار انسٹالیشن۔
  • انفراسٹرکچر آڈٹ کنٹرول: پیچ مینجمنٹ، ڈیٹا سیکیورٹی، پالیسی تعمیل اور سیکیورٹی بیسٹ پریکٹسز کی نگرانی۔
  • اہم سروسز کے لیے ہائی اویلیبلٹی (HA) حل کا قیام۔
  • GRR اور XIBO ایپلیکیشن سولیوشنز کا قیام اور ایڈمنسٹریشن۔
  • Windows Server 2022 پر Print Manager Plus 9 ایپلیکیشن سرور کی تعیناتی اور پرنٹر فلیٹ مینجمنٹ۔
  • سرور انفراسٹرکچر جدید کاری پروجیکٹ کی قیادت، بشمول Windows Server 2008 سے 2022 تک DNS مائیگریشن اور 2012 سے 2022 تک Active Directory مائیگریشن۔
  • Windows Server 2022 پر Remote Desktop Services (RDS) سرور کی انسٹالیشن اور کنفیگریشن۔

ورچوئلائزیشن:

  • Hyper-V انفراسٹرکچرز کی تعیناتی اور ایڈمنسٹریشن، ورچوئل مشینز کی تخلیق اور مینجمنٹ۔
  • ریپلیکیشن پر مبنی Hyper-V ہائی اویلیبلٹی (HA) آرکیٹیکچر کا قیام۔
  • Linux Debian 13 سرورز پر آن پریمائز Kubernetes کلسٹر کی تعیناتی (1 ماسٹر، 2 ورکر نوڈز) kubelet، kubeadm اور kubectl کے ساتھ۔
  • Proxmox 9 standalone سرور کی انسٹالیشن اور کنفیگریشن۔

بیک اپ:

  • Veeam کے ساتھ بیک اپ سولیوشن کا قیام اور ایڈمنسٹریشن۔
  • بیک اپ اور ریسٹور کی شیڈولنگ، مانیٹرنگ اور باقاعدہ جانچ۔

نیٹ ورکنگ:

  • Netgear آلات پر نیٹ ورک ایڈمنسٹریشن: VLAN کنفیگریشن، DHCP، IP ایڈریس مینجمنٹ، پورٹ سیکیورٹی اور نیٹ ورک انٹرکنیکشن۔
  • صرف HTTP/HTTPS ٹریفک کے ساتھ انٹرنیٹ پر ویب سرور پبلش کرنے کے لیے DMZ کنفیگریشن۔

آٹومیشن اور مانیٹرنگ:

  • Python اور PowerShell کے ذریعے ایڈمنسٹریشن ٹاسک آٹومیشن۔
  • Nagios Core کی تعیناتی اور Windows اور Linux سرورز کی مانیٹرنگ (ای میل نوٹیفیکیشن، کسٹم الرٹس)۔

ڈویلپمنٹ اور سپورٹ:

  • CRIO ویب سائٹ کے لیے چیٹ بوٹ کی ڈویلپمنٹ اور انٹیگریشن۔
  • PHP، HTML، CSS اور MySQL ڈیٹابیس مینجمنٹ کے ساتھ ویب ڈویلپمنٹ۔
  • صارف معاونت، ٹیم مینجمنٹ اور WikiJS کے ذریعے آئی ٹی دستاویزات و طریقہ کار کی تحریر۔

اپرنٹس سسٹمز ایڈمنسٹریٹر - Voltalis، پیرس

نومبر ۲۰۲۱ - ستمبر ۲۰۲۳

سسٹمز اور سروسز:

  • Windows Server ایڈمنسٹریشن: Active Directory (AD) اور DNS۔
  • Exchange Online کے ساتھ میل باکس مینجمنٹ: تخلیق، حذف، مشترکہ میل باکسز اور ڈسٹریبیوشن لسٹس۔
  • HP iLO سرور ایڈمنسٹریشن۔
  • موجودہ MySQL HA آرکیٹیکچر کے ساتھ MySQL سرور ایڈمنسٹریشن۔
  • Linux سرور ایڈمنسٹریشن: GitLab، GLPI، MySQL، Docker، Apache2۔
  • GitLab سرور مائیگریشن پروجیکٹ۔
  • آئی ٹی ہارڈویئر مینٹیننس۔

ورچوئلائزیشن:

  • Linux اور Windows ورچوئل مشینز کی تخلیق اور ایڈمنسٹریشن۔
  • متعدد ماحول کے ساتھ کلسٹر سرور پر Proxmox 6 سے Proxmox 7 مائیگریشن۔
  • ہائی اویلیبلٹی (HA) کے ساتھ Proxmox کلسٹرز کی ایڈمنسٹریشن: Ceph اور NFS اسٹوریج۔

آٹومیشن اور مانیٹرنگ:

  • Ansible کے ساتھ ٹاسک آٹومیشن: ضروریات کے مطابق Debian VM کنفیگریشن، رائٹس مینجمنٹ اور سروس انسٹالیشن۔
  • آفس ماحول کے لیے Debian پر CheckMK مانیٹرنگ سرور کا قیام۔
  • CheckMK کے ساتھ پروڈکشن اور پری پروڈکشن ماحول کی مانیٹرنگ: ای میل نوٹیفیکیشنز اور کسٹم الرٹس۔

دستاویزات اور سپورٹ:

  • Jira، Confluence اور GLPI کے ذریعے تکنیکی طریقہ کار کی تحریر اور صارف معاونت۔
  • GLPI کے ذریعے Voltalis دفاتر کی آئی ٹی اثاثہ انوینٹری مینجمنٹ۔
